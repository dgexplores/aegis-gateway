Kill switch

Refuses every request from every tenant. Use it when something is wrong everywhere and you need the gateway to stop talking to providers at all.

No break-glass secret is set, so any signed-in operator can refuse all traffic. Set AEGIS_BREAKGLASS_PASSWORD to require a second secret for it.

Tenants

Pause refuses that tenant's traffic and leaves its documents and history alone. Waive the soft band stops known-noisy callers being refused for suspicious input — it cannot waive a hard injection block, and there is no control anywhere that could.
