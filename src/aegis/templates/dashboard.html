Capabilities

Five production-grade primitives behind one endpoint

Injection Defense

Three-band scanner catches instruction overrides, encoded payloads, role-tag smuggling, and exfiltration attempts before the model sees them.

PII Vault

Reversible pseudonymization for emails, cards, Aadhaar, PAN, passport, UPI. Provider never sees raw values; caller gets them restored.

Tamper-Evident Audit

HMAC-signed hash chain. Every record re-verified on read: signature, linkage, payload digest. Rotation carries head forward.

Hybrid RAG

BM25 + hashed vectors with RRF fusion. Per-tenant isolation. Postgres source-of-truth with embeddings column. Eval-gated CI.

Budgets & Breakers

Per-tenant rate limits, daily token budgets, circuit breakers, failover to echo. Never 500 if fallback exists.
