How a request flows

Six stages. Every one of them leaves a record.

  1. 1

    Intake

    Authenticate the caller, resolve the tenant, check the rate limit and the budget.

  2. 2

    Screen

    Scan the prompt for injected instructions and exfiltration intent. Score it against two bands.

  3. 3

    Vault

    Swap emails, cards and keys for reversible pseudonyms. The original never leaves.

  4. 4

    Route

    Pick a provider by tier. Fall over to the next one on a timeout or a refusal.

  5. 5

    Restore

    Put the real values back in the answer, so the model never sees the real values either.

  6. 6

    Seal

    Append the turn to a hash-chained audit record. Tampering breaks the chain.

Capabilities

Five production-grade primitives behind one endpoint.

Injection Defense

Three-band scorer: pattern hits, Unicode smuggling, exfiltration probes, and scripted attempts to erase earlier instructions. A hard hit is refused before the provider is called; a soft hit is shielded in the middle band.

PII Vault

Reversible pseudonyms for emails, cards, IBANs, national IDs, API keys and passports. The provider sees the alias; you see the value restored.

Tamper-Evident Audit

HMAC-signed hash chain. Every read re-verifies the run, the sequence, the payload digest and the previous link.

Hybrid RAG

BM25 + vectors + fuzzy fusion. Per-tenant isolation. Poisoning filter. Every source-first answer carries citations.

Budgets & Breakers

Per-tenant rate and daily token budgets, circuit breakers, failover to the next provider. Never 500 on a provider fault.

Why it is built this way

Python 3.11–3.14, one dependency-light process

Runs as a container or a bare process. Postgres optional: SQLite by default, Postgres for multi-pod audit writes and shared RAG.

Fail-closed by default

A scanner error does not become an allow. Deny on doubt, and say so in the record.

Eval-gated CI

Injection recall, benign false-positive rate and retrieval quality are release gates, not dashboard numbers. A regression blocks the merge.

Bring your own model

OpenAI, Anthropic and a configurable OpenAI-compatible endpoint, plus a deterministic echo provider for tests. Swap by environment variable, not a fork.
